# CRTX Examples Index

This directory contains standalone, reproducible examples demonstrating the core value of CRTX as a filesystem-native coordination runtime.

| Example | What it shows | Estimated Time |
|---|---|---|
| [01-multi-agent-handoff](./01-multi-agent-handoff) | The core CRTX workflow. How one agent researches and creates a Capsule, and another agent implements without losing context. | 2 mins |
| [02-chat-recovery](./02-chat-recovery) | Zero Context Loss. How to resume a complex refactoring task after an IDE crash using only the filesystem state. | 2 mins |
| [03-provider-switch](./03-provider-switch) | Provider Independence (Capability Routing). How a task moves from a Research agent (e.g. Claude) to a Security agent (e.g. Gemini) flawlessly. | 3 mins |

**We highly recommend running the examples in order (01 -> 02 -> 03) to fully grasp the CRTX architectural paradigm.**
