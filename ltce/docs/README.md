# CRTX Runtime v1.0

CRTX is a minimal, production-ready, single-node execution runtime for autonomous agents and workflows. Built with a focus on simplicity, Developer Experience (DX), and reliability.

## Overview
CRTX is built on a microkernel architecture backed by a WAL-enabled SQLite persistence layer. It provides a robust pipeline for executing tasks via isolated, interchangeable plugins.
