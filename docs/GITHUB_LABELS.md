# GitHub Labels

We use a standardized set of labels to organize issues and pull requests.

| Label | Description |
|---|---|
| `bug` | Something isn't working as expected. |
| `enhancement` | New feature or request. |
| `documentation` | Improvements or additions to documentation. |
| `good first issue` | Good for newcomers. |
| `help wanted` | Extra attention is needed from the community. |
| `architecture` | Core protocol, design, or structural decisions. |
| `runtime` | Issues related to execution, LTCE, or routing logic. |
| `memory` | Issues related to state, `Capsules`, or `Evidence`. |
| `plugin` | Issues related to external integrations, models, or MCP. |
